# Genetic Analysis and GWAS

A research project focused on genetic analysis and Genome-Wide Association Studies (GWAS), with an initial focus on chromosome 14.

## Project Structure

- `data/`: Raw and processed datasets.
- `scripts/`: Analysis scripts and pipelines.
- `results/`: Generated outputs, figures, and reports.

## Analysis Workflow

- Genetic data exploration
- Quality Control (QC)
- Linkage Disequilibrium (LD)
- Population Structure and PCA
- Genome-Wide Association Studies (GWAS)

## Tools

- Python
- PLINK
- Bash
- R (when applicable)
